# Japan Freight Operations Study

RushLabsの貨物運行管理者試験学習アプリ向け案内サイト。日本語・英語・韓国語で学習内容、オフライン利用の範囲、プライバシーと問い合わせ先を案内します。アプリは公開準備中です。

Static HTML/CSS/JavaScript. No account, analytics, backend, or external fonts.

```sh
npm run build
npm run check
npm run preview
```

GitHub Pages base path: `/jp-freight-operations-study-web/`. Store links are intentionally absent until the app is publicly available and its exact identity is verified.
